# Quickstart: Single-Character Demo

## Goal

Produce one complete text-first MV package before generating images, music, or video.

## Recommended Demo Character

Start with Sun Wukong or another public-domain mythological/literary character. The first demo should avoid modern copyrighted designs and celebrity likenesses.

## Run Order

1. Pick one character and one short-video format.
2. Create a research packet with source notes and uncertainty labels.
3. Summarize the character's life as a dramatic story.
4. Extract spirit keywords, emotional color, music direction, and audience hook.
5. Define the universe premise: why this character sings, how views convert into power, and why the host/system needs the performance.
6. Generate a song package for Suno-like tools.
7. Create a visual bible with stable identity anchors and copyright-safe boundaries.
8. Draft a 30-90 second storyboard with shot prompts and motion prompts.
9. Run review gates: text, lyrics, visual identity, storyboard, compliance.
10. Only after approval, generate the first music track, first reference image, and first short video test.

## Demo Exit Criteria

- The package can be handed to another creator without verbal explanation.
- Every stage has an owner type: Agent, Existing Tool, Human Review, or Future Scale Pipeline.
- The same template can be reused for a second character.
- The project owner can identify which agents are worth building first.
