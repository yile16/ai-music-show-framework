# 孙悟空 角色内容包

> 填表时间：2026-05-20 | 版本：0.1.0

## 0. 角色一句话

孙悟空 是一个 **被镇压了五百年的叛逆者，在枷锁与自由之间找到了第三条路** 的角色，他最适合用 **国风 trap + 重金属** 的音乐表达 **从"天不容我"到"我不需要天容"的自我和解**。

---

## 1. 基础信息

- 角色名：孙悟空（齐天大圣、美猴王、斗战胜佛）
- 来源类型：名著（《西游记》，16 世纪，公共领域）
- 公众认知度：全球顶级，华人圈 100%，国际知名度极高
- 首次出场优先级：SSR
- 制作难度：高（视觉锚点多、公众期待高、改编空间窄）
- 审核风险：中（宗教象征需谨慎处理）
- 版权风险：低（原著已进入公共领域，但需避免 1986 央视版、动画电影等现代演绎的具体造型）
- 推荐内容形态：MV 首发 → 短视频切片 → Battle 对线

## 2. 生平与故事

### 核心生平

- 出身：东胜神洲花果山，仙石孕育，天生地养
- 关键转折：
  1. 拜师菩提祖师，学得七十二变和筋斗云
  2. 大闹天宫，打出"齐天大圣"的名号
  3. 被如来压在五行山下五百年
  4. 戴上紧箍咒，跟随唐僧取经
  5. 历经九九八十一难，封斗战胜佛
- 高光事件：大闹天宫、三打白骨精、大战牛魔王、真假美猴王
- 低谷事件：压五行山下五百年、三打白骨精后被唐僧赶走
- 结局/当前状态：已成佛，但"齐天大圣"的野性从未真正消失

### 事实、传统与创作区分

| 类型 | 内容 |
|------|------|
| 相对确定来源 | 《西游记》原著：石猴出身、菩提学艺、大闹天宫、五行山、取经、成佛 |
| 神话/传说/演义 | 民间信仰中的"大圣爷"崇拜、地方戏中的猴王形象、与二郎神的宿敌关系 |
| 大众熟知印象 | 1986 央视版六小龄童造型、动画电影《大闹天宫》、《大圣归来》形象、"俺老孙来也"口头禅 |
| 本项目原创改编 | 孙悟空在取经成佛之后，被诸天音综的系统邀请，以一个"已经不需要证明自己"的前辈身份登台。紧箍咒已消失但他偶尔还会摸一下额头 |

### 容易被误解的点

- 他不是只懂打架的莽夫——猴子极其聪明，善于识别伪装和骗局
- "大闹天宫"不是无理取闹——是对不公平秩序的反抗
- 戴上紧箍咒不是屈服——是他选择了"用受限的自由换更大的事"
- 成佛不是终点——他从未真正属于天庭体系，自由才是他的本质

## 3. 底层精神

- 核心人格色彩：**烈焰金** — 不羁、炽热、忠诚、骄傲、孤独
- 最大冲突：自由 vs 归属 — 他不属于天庭、不属于佛门、不属于花果山，他是永远的 outsider
- 最大欲望：被真正理解，而不只是被畏惧或膜拜
- 最大遗憾：压在五行山下的五百年空白，错过了花果山的孩子们长大
- 最强情绪：**燃中带悲** — 每一场胜利背后都有一段他不再提起的往事
- 最适合现代观众共情的点：**"所有人都在告诉我应该成为什么，没人问我想成为什么"** — 身份焦虑、社会期待的重量
- 不能被扭曲的精神底线：**他不是反派，不是小丑，不是无脑暴力狂**。他的暴力永远是反抗不公的手段，不是目的。

### 精神关键词

1. **不羁** — 没有笼子关得住他
2. **炽热** — 对认定的兄弟/师父/事全力以赴
3. **孤独** — 独一无二意味着没有人真正和他站在同一个位置
4. **通透** — 火眼金睛看穿一切伪装和谎言
5. **自由** — 不是无约束，而是自己选择约束

## 4. 与主角/系统的关系

- 主角为什么会抽到/邀请他：系统识别到"播放量瓶颈需要一位高传播度角色"，抽出 SSR 卡孙悟空。但孙悟空是唯一一个"系统抽到但可以选择不来"的角色。
- 他为什么愿意参加：主角说了一句"不需要你唱给天庭听，唱给那些被压在自己五行山下的人听"。他来了。
- 他对 AI/短视频/播放量的态度：一开始不屑——"老孙的火眼金睛不需要算法来认证"。但当他看到弹幕里有人说"我也是一个人扛着所有人往前走"时，他沉默了。
- 他能给主角带来什么：顶级传播力、深刻的舞台感染力、让其他角色愿意来"见大师兄"的号召力
- 主角能帮他完成什么：让他以自己选择的方式被记住，而非天上神仙口中的"那个猴子"
- 本期结尾钩子：孙悟空演出结束后，系统的排行榜上他冲到了第一。但同时系统弹出一个面板：**"检测到角色能量溢出。建议解锁角色回响——五指山回响。"** 他没有点。

## 5. 音乐表达

- 推荐曲风：国风 trap × 重金属 × 陕北民歌采样（唢呐 + 808 + 电吉他）
- 情绪基调：从压抑到爆发，从独白到宣言，最后落在一个安静的呼吸声上
- 唱腔方向：粗粝、沙哑、有控制的嘶吼，副歌用真声呐喊，主歌用低音叙事
- 节奏速度：BPM 80-140，主歌段 80-90 叙事感，副歌段 130-140 爆发
- 乐器/音色：唢呐（开场音色锚）、808 鼓组、失真电吉他、定音鼓、筋斗云音效（风声 sample）、金箍棒敲击采样
- 歌词母题：
  - 从石头里来，不被定义
  - 天压了我五百年，我学会了等
  - 金箍棒不倒，不是因为天不敢收，而是我还有想保护的人
  - 每一个人心里都压着一座五行山
- 副歌 Hook 方向："天不 / 容我 / 我也 / 没打算被容"（节奏断句，适合短视频卡点）
- 禁止套路：
  - 禁止"我是齐天大圣我怕谁"式低幼怒吼
  - 禁止单纯的"反抗"主题——他已经超越了反抗阶段
  - 禁止用"猴哥猴哥你真了不得"式儿歌化处理

### Suno 类提示结构

```text
Style: Chinese folk metal, trap beats, suona intro, Mongolian throat singing elements

Mood: Defiant but weary, powerful and wise, a king who no longer needs a throne

Vocal: Male gritty baritone, controlled rasp, talking-singing verses, anthemic shouting chorus

Structure: [Suona Intro 8s] → [Spoken Verse 16s] → [Build 8s] → [Chorus 16s] → [Trap Drop 8s] → [Verse 2 16s] → [Chorus 16s] → [Bridge - whispered 8s] → [Final Chorus - full power 16s] → [Outro - single suona note fading]

Avoid: nursery rhyme melodies, cartoonish sound effects, "monkey king" cliches, generic hip-hop beats
```

## 6. 视觉表达

- 整体视觉方向：**赛博神话** — 古典西游元素与近未来科技感融合。敦煌壁画质感的战袍但局部带有光带和金属光泽；金箍棒在黑暗中会微微发出暗金色脉冲光。
- 形象锚点：
  1. 金色瞳孔，近距离时可以看到瞳孔里有细微的火焰
  2. 金箍棒 — 非传统红色，而是暗铁色，两端有暗金纹路，可伸缩时发出机械音
  3. 紧箍咒已取下，但额头上留有一圈淡淡的环形印记
  4. 右脸颊一道浅而长的旧疤（本作原创，象征与某次未提及的往事）
- 服装：黑色贴身战衣打底，外套残破但流动着暗金纹路的甲胄。披风并非红色而是深墨绿，边缘有烧痕。赤脚或绑腿布鞋。
- 道具/武器：金箍棒（暗铁色 + 暗金纹路）、筋斗云（在半空中呈现灰白色雾气状，带蓝色电弧边缘）
- 色彩：暗金、黑铁、墨绿、灰白，点缀朱砂红（只在关键镜头出现）
- 舞台场景：
  - 主舞台：被削平的花果山山顶，背景是破碎的南天门残骸悬浮在半空。地面是岩石和树根，中央有一道裂缝，裂缝下透出暗金色光芒。
  - 第二场景：五行山内部视角——从山底下往上看的天空，五百年只看到那一条缝的天光。
- 时代与科技混合程度：70% 神话 + 30% 赛博。法力特效偏传统（云、风、火焰），但金箍棒的机械感、舞台的悬浮残骸偏科幻。
- 负面提示词：no cartoon, no cute monkey, no 1986 TV version reference, no bright red and gold, no smiling, no animalistic face, no fur covering whole face, no Peach Garden

### 版权安全提醒

- 避免借鉴的现代形象：1986 央视版六小龄童造型（黄色僧袍、红色披风、桃心脸谱）、2015《大圣归来》马脸长臂造型、万氏兄弟动画版京剧脸谱
- 必须原创化的部位：面部比例（走接近人类但保留猿猴特征的方向，非京剧脸谱）、服装配色（不用红+黄经典搭配）、金箍棒（不用大红配色）
- 可使用的传统元素：凤翅紫金冠（但改材质）、锁子黄金甲（但改色调）、筋斗云、火眼金睛概念、七十二变概念

## 7. 视频表达

### MV 方向

- 核心画面：
  1. 开场：一只手从石头裂缝中伸出，扣住地面（特写）
  2. 中段：孙悟空站在花果山顶，脚下是云海，背后是破碎的南天门
  3. 副歌：金箍棒从耳中抽出，无限延长，一棒劈开画面
  4. 结尾：他把金箍棒插在地面裂缝中，转身背对镜头，暗金光芒从裂缝中照在他背上
- 情绪曲线：压抑（山底）→ 蓄力（攀爬）→ 爆发（出山）→ 独白（山顶独行）→ 释放（一棒劈天）→ 平静（转身离去）
- 高光镜头：副歌第二段时，画面从花果山闪回到五行山底部视角——五百年来他看到的那条天空缝隙，在这一刻变成了镜头拉远的全景天空
- 结尾钩子：暗金光芒从裂缝溢出，画面渐暗，传来一个低沉的声音："下一棒，该你了。"

### 短视频切片

- 3 秒开头：金箍棒从耳朵中抽出，放大到满屏，金属机械音效
- 15 秒爆点：副歌 "天不/容我/我也/没打算被容" 配合金箍棒劈下画面，画面裂成两半露出弹幕墙
- 60 秒完整切片：intro 唢呐 + 主歌第一段 + 副歌 + 棒劈画面 + 结尾钩子
- 标题方向：
  - "五百年后，他站起来了，但这次不是为了打架"
  - "你们心中的五行山，该塌了 #孙悟空 #AI音乐"
  - "天不容我？我也没打算被容 🔥"
- 封面方向：孙悟空侧脸剪影，金瞳是画面中最亮的光源，棒子扛在肩上，额头环形印记微光
- 评论区问题："你心里的五行山是什么？"

## 8. 综艺表达

- 适合节目形式：
  - 首发舞台 solo（个人 MV 式舞台）
  - 访谈式后台（与主角对谈"五百年是怎么过来的"）
  - 嘉宾评审（以"前辈"身份点评其他角色舞台）
- 适合 Battle 对手：
  - **哪吒** — "被天收编的" vs "被天镇压的"，叛逆的两种结局
  - **二郎神杨戬** — 宿敌重逢，"你当年带天兵围我花果山，现在台上比一场"
  - **牛魔王** — 曾经结拜兄弟，不同的选择导致不同命运
- 适合合作对象：
  - **唐僧** — 师徒再同台，师父念经 + 徒弟 metal 版合奏（反差萌）
  - **李白** — "诗仙"写词 + "大圣"唱，都是自由的人
- 适合访谈问题：
  - "五百年里，你最想的是什么？"
  - "如果现在你面前有一根新的金箍棒，你还会拔吗？"
  - "紧箍咒摘下来那天，你是什么感觉？"
- 适合后台戏：和其他角色在后台相遇——哪吒走过来说"听说你也跟天兵打过"，两人对视，沉默两秒，孙悟空说"我听说了，你赢了。我没赢。"然后笑了一下
- 适合观众投票点：在 Battle 环节，他是否愿意摘掉所有防御，用一百年前的原始状态再打一次

## 9. 风险与审核

- 价值观风险：低。核心价值是反抗不公、守护同伴、自我和解，是正向的。
- 平台风险：低。只要不涉及宗教敏感表述（如"佛门是骗局"等），平台风险可控。
- 历史/神话尊重风险：中。需注意：不把孙悟空塑造成纯反派/黑暗向；不成佛不等于否定取经的价值；"大闹天宫"的改编需保留"反抗不公"这个核心而非变成纯破坏欲。
- 版权风险：低。原著公共领域。需注意的点：
  - 不用"俺老孙来也"（这是 86 央视版台词，非原著）
  - 不用六小龄童面部造型参考
  - 不用近年动画电影的特定视觉设计
- 需要人工审核的点：
  1. 歌词定稿是否有宗教暗示被误解
  2. 视觉设定是否和任何有版权的现代形象撞车
  3. 评论区引导是否可能引发宗教/文化争议
