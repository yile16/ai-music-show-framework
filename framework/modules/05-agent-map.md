# 模块 05：Agent 与 Scale 地图

## 原则

不是每个环节都要一开始做 Agent。

判断标准：

- 重复发生
- 需要结构化输出
- 需要跨资料整合
- 需要质量判断
- 需要和其他流程衔接

## 第一批 Agent

| Agent | 作用 | 阶段 | 优先级 |
|-------|------|------|--------|
| 角色研究 Agent | 收集资料、区分事实/传统/创作 | 角色内容包 | P1 |
| 精神提炼 Agent | 提炼人格色彩、冲突、音乐方向 | 角色内容包 | P1 |
| 小说入口 Agent | 设计主角如何遇到角色和任务钩子 | 小说化入口 | P1 |
| 歌曲方案 Agent | 生成曲风、歌词结构和音乐提示 | 音乐方案 | P1 |
| 视觉设定 Agent | 生成版权安全的角色视觉和舞台设定 | 视觉设定 | P1 |
| 分镜 Agent | 生成 shot-level 分镜 | 分镜脚本 | P2 |
| 导演 Agent | 设计综艺效果、冲突和名场面 | 节目策划 | P2 |
| 审核 Agent | 检查价值观、版权、平台风险 | 审核 | P1 |
| 工具发现 Agent | 搜索成熟工具/技能，避免重复开发 | 全流程 | P2 |
| 数据结算 Agent | 根据播放数据计算排名和奖励 | 数据结算 | P3 |

## 哪些先不用 Agent

- 最终审美判断
- 最终发布决定
- 法律责任判断
- 复杂商业合作判断
- 第一版平台架构

这些先由人做，等流程稳定后再辅助化。

## Scale 优先级

### 第一阶段：手动 + 模板

- 用文档模板跑通
- 用一个角色验证
- 用人工选择工具

### 第二阶段：半自动 Agent

- 角色包自动生成
- 歌曲提示自动生成
- 视觉提示自动生成
- 分镜自动生成
- 审核清单自动生成

### 第三阶段：资产库

- 角色库
- 名场面库
- 提示词库
- 音乐风格库
- 舞台库
- 失败案例库

### 第四阶段：流水线

- 批量角色候选
- 批量脚本方案
- 批量图像提示
- 批量视频片段
- 数据回流
- 排名和返场推荐
