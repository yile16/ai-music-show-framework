# 模块 09：叙事引擎

> 解决"有角色包但不知道怎么变成故事"的问题。
> 本模块提供从角色内容包到小说化入口、MV 叙事、综艺脚本的转换方法。

---

## 一、叙事在框架中的位置

```
角色内容包（模块 02）
        │
        ▼
  叙事引擎（本模块）  ←── 导演系统（模块 03）
        │
        ▼
  小说化入口 / MV 叙事 / 综艺脚本
```

叙事引擎的角色：**把"角色是谁"翻译成"角色做了什么、为什么、观众怎么看"**。

---

## 二、核心叙事弧线

所有本项目的叙事单元（小说入口、MV、综艺桥段）统一使用以下五拍结构：

```text
┌─────────────────────────────────────────────────────┐
│  拍 1：登场 HOOK (0-10%)                            │
│  → 一个让人无法划走的画面/台词/冲突                  │
│                                                     │
│  拍 2：揭示 CONTEXT (10-30%)                        │
│  → 这个角色为什么在这里？他要面对什么？              │
│                                                     │
│  拍 3：对抗 CONFLICT (30-70%)                       │
│  → 核心矛盾爆发。音乐到这里应该是最高潮              │
│                                                     │
│  拍 4：转折 TURN (70-90%)                           │
│  → 不是简单的"赢了"，而是一种新的理解或状态          │
│                                                     │
│  拍 5：钩子 CLIFF (90-100%)                         │
│  → 留下的问题、下一期的暗示、系统的下一个提示         │
└─────────────────────────────────────────────────────┘
```

### 各拍的写作规则

#### 拍 1：登场 HOOK

| 元素 | 规则 |
|------|------|
| 时长 | 小说 200-300 字，MV 3-5 秒，综艺 5-8 秒 |
| 功能 | 建立"这个人不简单"的第一印象 |
| 禁用 | 不要介绍背景，不要旁白解释，用行动/画面说话 |
| 检验 | 如果这是一条短视频的开头 3 秒，我会停下来吗？ |

**示例（孙悟空）**：
> ❌ "孙悟空，曾经的齐天大圣，已经成佛五百年了，这一天他收到了一条奇怪的邀请..."
>
> ✅ "金箍棒从耳朵里抽出来的时候，发出了一声低沉的嗡鸣——像是它也等了很久。"

#### 拍 2：揭示 CONTEXT

| 元素 | 规则 |
|------|------|
| 功能 | 让观众理解"现在的状况"，但不是通过旁白 |
| 手法 | 对话、环境细节、系统面板弹出、其他角色反应 |
| 信息密度 | 只给必需的最小信息，剩下的让观众脑补 |
| 检验 | 一个完全不知道西游记的人能看懂现在的局面吗？ |

#### 拍 3：对抗 CONFLICT

| 元素 | 规则 |
|------|------|
| 功能 | 角色面对核心矛盾，情绪推到最高 |
| 来源 | 来自角色包的"最大冲突"和"最大欲望"字段 |
| 音乐对应 | 这里必须是副歌/高光段落 |
| 检验 | 观众会不会想发弹幕？ |

**冲突来源速查表**（从角色包精神字段自动映射）：

| 精神关键词 | 典型冲突场景 |
|-----------|------------|
| 不羁/自由 | 被规则/系统/权威限制 |
| 孤独 | 被误解、无法被归类 |
| 炽热/忠诚 | 需要保护的人受威胁 |
| 遗憾 | 被迫面对过去的后果 |
| 骄傲 | 被轻视/被挑战 |

#### 拍 4：转折 TURN

| 元素 | 规则 |
|------|------|
| 功能 | 不是"打赢了"，而是"理解了"或"选择了" |
| 关键 | 这个转折必须来自角色的底层精神，不能从天而降 |
| 避免 | 机械降神（deus ex machina） |
| 检验 | 这个转折后，角色和 3 分钟前的他是不同的人了吗？ |

**转折类型**：
1. **和解型**：角色接受了之前一直抗拒的东西（如孙悟空接受"不需要被天容"）
2. **选择型**：在两个同样重要的东西之间做了选择（如选择保护某人而放弃力量）
3. **揭示型**：发现了之前不知道的真相（如火眼金睛看到了隐藏的敌人）

#### 拍 5：钩子 CLIFF

| 元素 | 规则 |
|------|------|
| 功能 | 让观众必须看下一期 |
| 类型 | 未解决的悬念 / 新角色暗示 / 系统新任务 / 角色关系的未完成对话 |
| 数量 | 至少 2 个钩子（一个明钩 + 一个暗钩） |
| 检验 | 如果观众看完这期后一周没有新内容，他还会记得这个钩子吗？ |

**钩子类型模板**：
- **明钩**（直接呈现）：系统弹出新提示 / 下一角色登场画面 / 排名变化
- **暗钩**（需要观众自己发现）：画面角落的细节 / 对话中的双关语 / 一首歌的歌词暗示

## 三、角色精神 → 情节转换表

这是叙事引擎的核心转换逻辑。输入角色包的"底层精神"字段，输出具体的情节设计。

```text
┌────────────────────┐     ┌───────────────────────┐
│ 角色包底层精神       │ ──→ │ 情节转换               │
├────────────────────┤     ├───────────────────────┤
│ 核心人格色彩         │ →   │ 登场方式 & 第一印象       │
│ 最大冲突            │ →   │ 对抗段落的核心矛盾        │
│ 最大欲望            │ →   │ 角色的"想要"驱动行动      │
│ 最大遗憾            │ →   │ 转折段的情感基底          │
│ 最强情绪            │ →   │ 音乐的情绪锚点            │
│ 共情点              │ →   │ 观众代入的窗口            │
│ 不被扭曲的底线       │ →   │ 叙事的禁区（绝对不能写）   │
└────────────────────┘     └───────────────────────┘
```

### 转换示例（孙悟空）

| 精神要素 | 值 | 情节转换 |
|---------|-----|---------|
| 核心人格色彩 | 烈焰金：不羁、炽热、孤独 | 登场：一个人站在花果山顶，背对镜头，金箍棒插在身旁 |
| 最大冲突 | 自由 vs 归属 | 对抗：系统要求他按规则表演，他拒绝，"老孙的歌不按节目单来" |
| 最大欲望 | 被真正理解 | 转折：发现弹幕里有人说"我也是一个人扛着"，他停顿了一拍 |
| 最大遗憾 | 五行山下五百年 | 钩子：系统提示"检测到角色能量溢出，建议解锁五指山回响" |
| 最强情绪 | 燃中带悲 | 音乐：副歌是燃的，bridge 是静的，结尾是一个呼吸声 |
| 共情点 | "所有人都在告诉我该成为什么" | 观众窗口：他和主角的对话——"你为什么来这个节目？""因为你说不需要我唱给天庭听。" |

## 四、不同内容形态的叙事适配

### 4.1 小说化入口（1500-3000 字）

```text
结构：
  登场 HOOK（200字） → 速建世界观
  揭示 CONTEXT（400字） → 主角当前状态 + 为什么邀请这个角色
  角色登场（500字） → 角色的第一印象、对话、态度
  冲突展开（600字） → 角色与主角/系统的张力
  转折 + 钩子（300字） → 角色接受了什么，留下了什么

叙事视角：第一人称"我"（主角视角）
节奏：每 500 字至少有一个"想划线"的句子
```

### 4.2 MV 叙事（30-90 秒）

```text
结构转化：
  小说叙事           →    MV 叙事
  ─────────────────────────────────
  登场 HOOK           →    Intro（3-5秒，最强视觉冲击）
  揭示 CONTEXT        →    Verse 1（画面建立角色和世界）
  对抗 CONFLICT       →    Chorus（高光镜头，动作/爆发）
  转折 TURN           →    Bridge（慢镜头/特写/情绪转换）
  钩子 CLIFF          →    Outro（最后1-2秒的定格/暗金光芒）

MV 叙事的特殊规则：
- 故事靠画面和音乐讲，不依赖文字
- 一个镜头只说一件事
- 情绪曲线必须和音乐结构严格对齐
- 结尾 1 秒定生死（那 1 秒决定观众是划走还是点赞）
```

### 4.3 综艺桥段（1-3 分钟）

```text
结构转化：
  小说叙事           →    综艺桥段
  ─────────────────────────────────
  登场 HOOK           →    开场冲突或意外（谁说了什么/谁来了）
  揭示 CONTEXT        →    角色访谈/后台对话/系统提示
  对抗 CONFLICT       →    Battle 环节 / 冲突对话 / 投票反转
  转折 TURN           →    角色反应 / 观众反应 / 弹幕墙
  钩子 CLIFF          →    下一位对手的剪影 / 排名变化的悬念

综艺桥段的特殊规则：
- 需要至少 2 个角色在场（独白不是综艺）
- 观众反应（弹幕/投票）是叙事的一部分
- 真实感 > 完美感（后台"意外"比排练好的好看）
- "名场面"的判断标准是：会不会有人截这段发到其他平台？
```

## 五、叙事质量评判清单

每一段叙事产出（小说/MV脚本/综艺脚本）在进入下一步之前，必须通过此清单：

### A. 基础过关（必须全部通过）

- [ ] 一个完全不了解这个角色的人能看懂发生了什么
- [ ] 看完后能用一句话说出"这期讲了什么"
- [ ] 开头的 5 秒/200 字内有让人想继续看的东西
- [ ] 没有"旁白解说式"的信息倾倒
- [ ] 角色的行为符合其底层精神（不 OOC）

### B. 质量跃升（至少通过 3 项）

- [ ] 有一个"想截图的画面"或"想划线的句子"
- [ ] 有一个让人意外的转折（但回头想又合理）
- [ ] 情绪不是单一的——笑中有泪、燃中有悲
- [ ] 有一个细节会在第二遍看的时候被发现
- [ ] 结尾让人想看下一期

### C. 红线（任何一项触发即驳回）

- [ ] 角色被恶搞或贬低
- [ ] 冲突解决依赖"突然的力量"或"外人救场"
- [ ] 有 AI 味——大段排比、空洞抒情、正确的废话
- [ ] 性别/族群/宗教的任何冒犯性表达

## 六、叙事资产库（建设中）

随着每个角色包完成，沉淀以下叙事资产：

| 资产类型 | 格式 | 示例 |
|---------|------|------|
| 登场方式模板 | 一句话 + 镜头描述 | "背对镜头站在高处，武器在身边" |
| 钩子模板 | 一句话 + 悬念类型 | "系统提示：检测到能量溢出" |
| 名场面卡片 | 场景名 + 情绪 + 为什么有效 | 见导演系统桥段库 |
| 失败案例 | 本来想写什么 + 为什么没用 | 待积累 |

## 七、与其他模块的关系

```
模块 02（角色内容包）
  → 提供：精神关键词、最大冲突、最大欲望、共情点
  → 接收：叙事中发现的角色深度补充（回写角色包）

模块 03（导演系统）
  → 提供：综艺桥段模板、情绪曲线参考
  → 接收：叙事中产生的新桥段创意（回写桥段库）

模块 04（生产流程）
  → 阶段 3"小说化入口"直接使用本模块的五拍结构
  → 阶段 7"分镜脚本"直接使用本模块的 MV 叙事转化

模块 08（质量评估）
  → 每次叙事产出后用评判清单自检
```
