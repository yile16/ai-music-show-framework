# 模块 01：世界观与系统机制

## 主角定位

主角以“我”的视角展开，是宇宙音综的制作人、导演、经纪人和 AI 制作能力持有者。

主角拥有一个与 AI 内容制作和播放量结算相关的系统。系统不是单纯外挂，而是整个项目的叙事引擎、生产引擎和运营引擎。

## 系统核心

```text
播放量越高 → 系统资源越多 → 可邀请角色越强 → 制作能力越高 → 节目规格越大
```

## 三大主系统

### 1. 抽卡/邀请系统

用于决定主角能遇到、邀请或解锁哪些角色和制作资源。

可抽取对象：

- 角色卡
- 场景卡
- 舞台碎片
- 事件卡
- 能力卡
- 组合卡

角色等级建议：

| 等级 | 含义 | 示例 |
|------|------|------|
| N | 低风险原创或普通角色 | 原创乐手、地方传说人物 |
| R | 小众历史/传说角色 | 地方名人、民间角色 |
| SR | 有认知度的重要角色 | 牛魔王、铁扇公主、苏小妹 |
| SSR | 高认知、高传播、高难度角色 | 孙悟空、李白、哪吒、秦始皇 |
| UR | 文明级、神系级、超高难度角色 | 女娲、盘古、宙斯、奥丁 |

等级不只代表强度，也代表制作难度、审核风险、观众期待和内容复杂度。

### 2. 制作能力系统

用于决定主角能把内容制作到什么规格。

能力树：

- 时空取景：录音棚 → 虚拟舞台 → 历史街巷 → 神话场景 → 跨宇宙战场
- 舞台搭建：单人布景 → 乐队 → 舞团 → 灯光机关 → 神话级舞美
- 镜头调度：固定镜头 → 运镜 → 多机位 → 电影化剪辑 → 直播级转播
- 观众系统：无观众 → 虚拟观众 → 弹幕入场 → 万界观众席 → 全民投票
- 角色互动：单人 MV → 访谈 → 双人合作 → Beef/Battle → 团队赛
- 资产稳定：一次性生成 → 角色形象锁定 → 场景复用 → 连续剧集统一
- 发行能力：单平台发布 → 多平台切片 → 标题封面优化 → 数据回流 → 排名赛制

### 3. 竞技榜单系统

用于决定角色返场、晋级、Battle 和综艺正赛资格。

榜单名称暂定：人气战力榜。

基础公式：

```text
人气战力值 = 播放量分 × 0.50 + 点赞分 × 0.25 + 评论分 × 0.15 + 收藏分 × 0.10
```

后续可扩展：

- 完播率
- 转发率
- 争议度
- 返场呼声
- 组合潜力
- 商业适配度

## 隐藏系统：角色回响

### 定位

赋能型系统暂不作为主玩法，但保留为情感奖励。当角色累计热度达到阈值时，解锁”角色回响”剧情。它提供小说深度，但不阻塞生产流程。

### 触发条件

| 条件 | 阈值建议 | 说明 |
|------|---------|------|
| 累计播放量 | ≥ 50 万 | 角色已经积累了足够的公众认知 |
| 单期爆发 | 单期播放量 ≥ 10 万 | 某期特别出圈 |
| 观众投票 | ≥ 1000 票 | 观众主动要求看”角色背后的故事” |
| 连发三期 | 同角色连续 3 期内容 | 角色已经有足够的内容厚度 |

满足以上 **任意 2 项** 即可触发。

### 回响剧情设计

回响不是角色的”高光时刻 replay”，而是**角色最脆弱、最被误解、最不愿提起的那个瞬间，以新的方式被重新讲述**。

| 角色 | 回响名 | 核心场景 | 情感内核 |
|------|--------|---------|---------|
| 孙悟空 | 五指山回响 | 从山底的视角看天空。五百年里，他看到了什么、想了什么、为什么没有放弃？ | “被压在最底下的时候，是什么让他相信天还会亮” |
| 李白 | 长安月下回响 | 他被”赐金放还”的那个夜晚，一个人站在长安城外，月光照在酒杯里。 | “全世界都在歌颂他的诗，没人问他还想不想写” |
| 哪吒 | 陈塘关回响 | 剔骨还父、削肉还母的那一天。不是愤怒，是”我做了一切你们还是说我不对”的孤独。 | “最疼的不是剔骨，是剔骨之后没有人说疼” |

### 回响的叙事结构

回响是一段 500-1000 字的文字叙事（配 1 张插画或 1 个氛围视频），结构：

```text
1. 触发（100字）：系统提示”角色回响已解锁”，主角看到一段不属于这个世界画面的碎片
2. 沉浸（400字）：以角色第一人称/近距离第三人称，进入那个最脆弱的时刻
3. 转折（200字）：不是改变了历史，而是角色对那段经历有了新的理解
4. 回归（100字）：画面回到现在，角色站在舞台上。他的眼睛里多了一层东西。
5. 暗示（50字）：系统提示”检测到新的角色回响可解锁：___”
```

### 回响的产出物

- 一篇 500-1000 字回响文字（发布到 B站专栏/小红书图文）
- 一张氛围插画（AI 生成 + 人工调色）
- 可选的 15 秒回响短视频（用于抖音 teaser）
- 回响解锁后，角色的”角色内容包”中新增一条：**回响信息**（回响名、触发条件、情感内核）

### 为什么回响重要

1. **深度差异化**：其他 AI 内容可以模仿你的 MV 格式和视觉风格，但模仿不了角色回响的情感深度。
2. **社区货币**：回响剧情是粉丝之间讨论、转发、二创的最佳素材。
3. **角色升级**：解锁回响后，角色在后续内容中的表演会有微妙变化（比如孙悟空回响后，他的眼神多了一层东西），这让”连续观看”有了叙事奖励。
4. **长期护城河**：10 个角色 × 每个角色的回响 = 一个情感宇宙。这是纯工具流 AI 内容做不到的。
