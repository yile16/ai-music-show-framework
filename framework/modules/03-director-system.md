# 模块 03：节目导演系统

## 定义

节目导演系统负责把角色内容包加工成“有节目效果”的内容。

它不是单纯写分镜，而是研究观众为什么会看、哪里会停留、哪里会转发、哪里会想看下一期。

## 导演系统的任务

1. 收集综艺和音综名场面。
2. 建立节目桥段库。
3. 为角色设计登场、采访、冲突、Battle、反转和投票。
4. 判断角色之间的组合效果。
5. 将小说剧情转化成可拍、可剪、可传播的视频结构。

## 导演角色拆分

### 综艺研究员

负责收集和整理成熟综艺模板。

研究对象：

- 音乐综艺
- 竞技综艺
- 脱口秀/访谈
- 演唱会互动
- 短视频爆款模板
- 影视名场面结构

输出：

- 名场面卡片
- 节目机制卡片
- 冲突模板
- 反转模板
- 观众投票模板

### 节目总导演

负责一期内容的整体节目效果。

输出：

- 本期主题
- 嘉宾组合
- 冲突点
- 情绪曲线
- 高光时刻
- 结尾钩子

### 舞台导演

负责舞美、镜头、调度和场景。

输出：

- 舞台概念
- 灯光方向
- 机位设计
- 运镜策略
- 舞团/乐队/群演安排

### 爆点剪辑师

负责判断短视频传播切片。

输出：

- 3 秒开头钩子
- 15 秒爆点
- 60 秒完整切片
- 标题方向
- 封面方向
- 评论区引导问题

### 审片人

负责判断内容是否无聊、过满、AI 味重、价值观不稳或有违规风险。

输出：

- 内容风险
- 节奏问题
- 角色偏离问题
- 修改建议

## 综艺桥段库字段

- 桥段名称
- 来源节目/类型
- 观众爽点
- 适合角色
- 适合关系：宿敌、师徒、队友、对手、陌生强者
- 情绪类型：燃、虐、笑、震撼、反转、争议
- 可改编方式
- 风险点

## 初始研究顺序

1. 音乐竞技类：先研究舞台、PK、评委反馈和投票机制。
2. 爆款短视频类：研究开头 3 秒、节奏、反转、标题。
3. 演唱会类：研究舞台互动和粉丝情绪。
4. 访谈/真人秀类：研究后台戏、冲突、和解、反差。
5. 影视名场面类：研究情绪爆发和角色宿命感。
