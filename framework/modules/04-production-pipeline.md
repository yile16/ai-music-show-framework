# 模块 04：内容生产流程

## 总流程

```text
角色选择
→ 角色内容包
→ 小说化入口
→ 节目策划
→ 音乐方案
→ 歌词/音乐提示
→ 视觉设定
→ 分镜脚本
→ 审核
→ 生成素材
→ 剪辑发布
→ 数据结算
→ 返场/升级/抽卡
```

## 阶段 1：角色选择

输入：

- 候选角色
- 角色热度
- 制作难度
- 审核风险
- 当前系统能力

输出：

- 本期角色
- 选择理由
- 预期传播点
- 风险提示

## 阶段 2：角色内容包

输入：

- 角色资料
- 神话/历史/名著来源
- 大众认知

输出：

- 生平总结
- 精神内核
- 音乐方向
- 视觉方向
- 综艺潜力
- 审核边界

## 阶段 3：小说化入口

输入：

- 主角当前系统等级
- 角色内容包
- 本期任务

输出：

- 主角如何遇到角色
- 为什么邀请角色
- 角色为什么愿意参与
- 播放量/系统任务钩子
- 结尾悬念

## 阶段 4：节目策划

输入：

- 角色内容包
- 导演桥段库
- 当前系统能力

输出：

- 本期节目形式
- 情绪曲线
- 冲突/反转
- Battle 或合作对象
- 观众互动设计

## 阶段 5：音乐方案

输入：

- 角色精神
- 本期剧情
- 节目形式

输出：

- 曲风
- 歌曲主题
- 歌词结构
- Hook
- Suno 类工具提示

## 阶段 6：视觉设定

输入：

- 角色内容包
- 当前制作能力
- 舞台设定

输出：

- 角色形象
- 服装道具
- 舞台场景
- 色彩与镜头风格
- 图像生成提示

## 阶段 7：分镜脚本

输入：

- 歌曲结构
- 视觉设定
- 节目策划

输出：

- 镜头序列
- 每镜时长
- 画面提示
- 动作提示
- 音乐对应点
- 生成难度

## 阶段 8：审核

审核内容：

- 角色精神是否被尊重
- 价值观是否正向
- 版权风险是否可控
- 平台风险是否可控
- 是否有 AI 味过重的问题
- 是否有明确爆点

## 阶段 9：生成与发布

输出：

- 音乐
- 图片
- 视频片段
- 剪辑版本
- 标题
- 封面
- 简介
- 评论区引导

## 阶段 10：数据结算

输入：

- 播放量
- 点赞
- 评论
- 收藏
- 转发
- 观众反馈

输出：

- 人气战力值
- 角色排名
- 系统奖励
- 是否返场
- 是否进入 Battle/综艺正赛
