# 模块 02：角色内容包

## 定义

角色内容包是整个项目的最小核心资产。

一个角色内容包不是人物简介，而是能持续生成小说、歌曲、MV、综艺桥段和短视频切片的母体。

## 角色内容包结构

### 1. 角色基础信息

- 角色名称
- 来源类型：神话、历史、名著、传说、原创
- 公众认知度
- 版权风险
- 价值观风险
- 首次出场优先级

### 2. 生平与故事

- 核心生平
- 关键事件
- 关键关系
- 公众最熟悉的标签
- 容易被误解的点
- 可以创作改编的空间

### 3. 底层精神

- 核心人格色彩
- 最大冲突
- 最大欲望
- 最大遗憾
- 不能被扭曲的精神底线
- 可以被现代观众共情的点

### 4. 音乐表达

- 适合曲风
- 适合情绪
- 适合唱腔
- 歌词母题
- Hook 方向
- 禁止套路

### 5. 视觉表达

- 原创视觉方向
- 服装
- 武器/道具
- 舞台场景
- 色彩
- 形象锚点
- 负面提示词

### 6. 视频表达

- 适合做 MV 的桥段
- 适合做短视频的爆点
- 适合做采访的问题
- 适合做 Battle 的对手
- 适合做综艺的名场面类型

### 7. 角色关系

- 盟友
- 对手
- 宿敌
- 可组队角色
- 可制造冲突角色
- 可制造反差角色

### 8. 审核边界

- 不能恶搞的点
- 不能歪曲的点
- 容易违规的点
- 平台敏感点
- 版权敏感点

## 角色内容包的作用

```text
角色内容包
├── 生成小说章节
├── 生成音乐方案
├── 生成歌词提示
├── 生成视觉设定
├── 生成 MV 分镜
├── 生成综艺桥段
├── 生成短视频切片
└── 支撑角色返场与长期运营
```

## 判断一个角色包是否合格

- 能不能一句话说清这个角色为什么值得唱？
- 能不能提炼出 3 个以上视频爆点？
- 能不能设计至少 2 个 Battle/互动对象？
- 能不能形成稳定视觉形象？
- 能不能避免恶搞和违规？
- 能不能复用到小说、MV 和综艺三种形态？
