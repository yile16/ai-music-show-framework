# 模块 02：角色内容包

## 定义

角色内容包是整个项目的最小核心资产。

一个角色内容包不是人物简介，而是能持续生成小说、歌曲、MV、综艺桥段和短视频切片的母体。

## 角色内容包结构

### 0. 角色一句话

用一句话说明这个角色为什么值得被邀请到诸天音综。这是角色包的"电梯演讲"，任何拿到角色包的人应该先看这句就能理解方向。

格式：`[角色名] 是一个 ______ 的角色，他/她/它最适合用 ______ 的音乐表达 ______。`

### 1. 角色基础信息

- 角色名称
- 来源类型：神话、历史、名著、传说、原创
- 公众认知度
- 版权风险
- 价值观风险
- 首次出场优先级
- 制作难度
- 审核风险
- 推荐内容形态

### 2. 生平与故事

- 核心生平：出身、关键转折、高光事件、低谷事件、结局/当前状态
- 事实、传统与创作区分表（确定来源 / 神话传说演义 / 大众熟知印象 / 本项目原创改编）
- 关键关系
- 公众最熟悉的标签
- 容易被误解的点
- 可以创作改编的空间

### 3. 底层精神

- 核心人格色彩
- 最大冲突
- 最大欲望
- 最大遗憾
- 最强情绪
- 不能被扭曲的精神底线
- 可以被现代观众共情的点
- 精神关键词（3-7 个）

### 4. 与主角/系统的关系

- 主角为什么会抽到/邀请他
- 他为什么愿意参加
- 他对 AI/短视频/播放量的态度
- 他能给主角带来什么
- 主角能帮他完成什么
- 本期结尾钩子

### 5. 音乐表达

- 适合曲风
- 适合情绪
- 适合唱腔
- 节奏速度
- 乐器/音色
- 歌词母题
- Hook 方向
- 禁止套路
- Suno 类提示结构（Style / Mood / Vocal / Structure / Theme / Avoid）

### 6. 视觉表达

- 原创视觉方向
- 形象锚点
- 服装
- 武器/道具
- 舞台场景
- 色彩
- 时代与科技混合程度
- 负面提示词
- 版权安全提醒

### 7. 视频表达

- 适合做 MV 的桥段（核心画面、情绪曲线、高光镜头、结尾钩子）
- 适合做短视频的爆点（3秒开头、15秒爆点、60秒完整切片）
- 适合做采访的问题
- 适合做 Battle 的对手
- 适合做综艺的名场面类型
- 标题方向、封面方向、评论区引导问题

### 8. 综艺表达

- 适合节目形式
- 适合 Battle 对手
- 适合合作对象
- 适合访谈问题
- 适合后台戏
- 适合观众投票点

### 9. 风险与审核

- 价值观风险
- 平台风险
- 历史/神话尊重风险
- 版权风险
- 需要人工审核的点

### 10. 可复用资产

- 可复用歌词母题
- 可复用视觉锚点
- 可复用舞台元素
- 可复用剧情钩子
- 可复用 Battle 关系

## 角色内容包的作用

```text
角色内容包
├── 生成小说章节
├── 生成音乐方案
├── 生成歌词提示
├── 生成视觉设定
├── 生成 MV 分镜
├── 生成综艺桥段
├── 生成短视频切片
└── 支撑角色返场与长期运营
```

## 判断一个角色包是否合格

- 能不能一句话说清这个角色为什么值得唱？
- 能不能提炼出 3 个以上视频爆点？
- 能不能设计至少 2 个 Battle/互动对象？
- 能不能形成稳定视觉形象？
- 能不能避免恶搞和违规？
- 能不能复用到小说、MV 和综艺三种形态？
