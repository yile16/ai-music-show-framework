## 4. 根因分析

> 用"五个为什么"方法追溯数据背后的原因

### 如果数据好于预期：

- 为什么？→ 
- 具体是哪个环节起了作用？→ 
  - [ ] 角色本身自带流量
  - [ ] 开头的钩子有效
  - [ ] 音乐/视觉质量超出预期
  - [ ] 标题和封面点击率高
  - [ ] 平台推荐算法给了流量
  - [ ] 蹭到了热点/话题
  - [ ] 其他:

### 如果数据低于预期：

- 为什么？→ 
- 数据在哪个节点断崖了？→ 
  - [ ] 开头 3 秒跳出率高（钩子不够强）
  - [ ] 中段完播率下降（内容拖沓）
  - [ ] 互动率低（没有设计互动触发点）
  - [ ] 点击率低（标题/封面不吸引人）
  - [ ] 平台几乎没有推荐量（标签/话题/时机问题）
  - [ ] 其他:
