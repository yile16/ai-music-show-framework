# 诸天音综系统框架

## 一句话定位

这是一个以“我”为主视角、由播放量升级系统驱动的 AI 角色内容宇宙。它把神话、历史和大众熟知角色沉淀为可复用的角色内容包，再组合成小说剧情、音乐 MV、短视频切片、综艺 Battle 和全民音综事件。

## 核心公式

```text
角色内容包 + 导演系统 + AI 制作能力 + 播放量结算 = 可持续扩展的角色内容宇宙
```

## 基本原则

1. 先服务个人创作，不急于产品化。
2. 先跑通 A+B+D：内容工厂、IP 宇宙、个人创作系统。
3. 先做单角色内容包，再做多角色组合。
4. 小说是叙事入口，音乐和视频是传播出口，综艺是长期组织形式。
5. 所有角色必须尊重底层精神，不恶搞正向人物。
6. 所有昂贵生成动作之前必须先完成文字确认。
7. 所有流程都要沉淀为模板、资产库和可复用规则。

## 项目分层

```text
世界观总控
├── 主角与系统
├── 播放量升级规则
├── 抽卡与邀请机制
├── 制作能力树
└── 竞技榜单

角色资产层
├── 角色库
├── 角色内容包
├── 人物关系
├── 精神内核
└── 版权与价值观边界

内容生产层
├── 小说剧情
├── 音乐方案
├── 歌词与 Suno 提示
├── 视觉设定
├── 分镜脚本
└── 短视频发布素材

节目导演层
├── 综艺名场面库
├── Battle 机制
├── 后台戏与访谈
├── 冲突、反转、投票
└── 爆点剪辑判断

运营与规模化层
├── 播放量结算
├── 人气战力榜
├── 返场与晋级规则
├── 工具/技能发现
├── 提示词与资产复用
└── 商业化候选场景

外部工具与服务层（模块 07）
├── AI 音乐生成：Suno v5（via evolink）
├── AI 图片生成：Flux / Seedream（via evolink）
├── AI 视频生成：Kling / Seedance / Veo 3（via evolink）
├── MV 合成：ai-music-video 技能 + ffmpeg
├── 角色一致性：storyboard-consistent-character 架构参考
└── 统一 API 网关：evolink-media
```

## 最小闭环

第一阶段只追求跑通一个闭环：

```text
选择角色
→ 生成角色内容包
→ 小说化登场剧情
→ 音乐 MV 策划
→ 歌词与音乐提示
→ 视觉设定
→ 分镜
→ 审核
→ 生成首批素材
→ 发布
→ 数据结算
→ 决定返场/抽卡/升级
```

## 当前推荐路径

1. 先完善框架。
2. 再设计角色内容包模板。
3. 用孙悟空填第一版。
4. 产出“小说化剧情 MV”方案。
5. 做第一条 30-90 秒 Demo。
6. 根据数据和制作体验，决定哪些环节变 Agent，哪些环节用现成工具。
