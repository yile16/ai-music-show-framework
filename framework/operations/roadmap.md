## 时间与资源规划

### 各 Phase 预估时间（单人，每周 10-15 小时投入）

| Phase | 内容 | 预估时长 | 关键依赖 |
|-------|------|---------|---------|
| Phase 0 | 框架搭建 | ✅ 已完成 | - |
| Phase 0.5 | 工具链验证 | 1-2 周 | evolink API 注册 |
| Phase 1 | 单角色文本 Demo | 2-3 周 | Phase 0.5 验证通过 |
| Phase 2 | 单角色素材 Demo | 2-4 周 | Phase 1 文本定稿；API 费用预备金 |
| Phase 3 | 第二角色复用测试 | 2-3 周 | Phase 2 发布反馈 |
| Phase 4 | 小型音综单元 | 3-4 周 | 至少 2 个角色有完整内容 |
| Phase 5 | Agent 化 | 4-8 周 | Phase 2 后的流程痛点明确 |
| Phase 6 | 框架自我完善 | ✅ 大部分完成 | - |

**总预估**：从 Phase 0.5 到 Phase 4 跑通第一个小型音综，约 **3-5 个月**（单人）。

### 单期内容制作周期（预估，Phase 1-2 阶段）

| 步骤 | 预估耗时 | 可否并行 |
|------|---------|---------|
| 填写角色内容包（新角色） | 3-5 小时 | - |
| 写小说化入口 | 1-2 小时 | - |
| 设计音乐方案+歌词 | 2-3 小时 | 可和小说并行 |
| 视觉设定+定妆照生成 | 2-3 小时 | 歌词定稿后 |
| 分镜脚本 | 1-2 小时 | 音乐生成中 |
| 生成素材（图+视频+音乐） | 2-4 小时（含等待） | 批量提交后等结果 |
| 剪辑合成 | 2-3 小时 | - |
| 审核+修改 | 1-2 小时 | - |
| 发布+运营（首 24h） | 1-2 小时 | - |
| **新角色总计** | **15-26 小时** | 约 3-5 个工作日 |
| **复用角色（已填包）** | **8-14 小时** | 约 2-3 个工作日 |

| 阶段 | 频率 | 说明 |
