# 风险登记册

> 汇总项目中所有已识别风险，每 Phase 结束时审查一次。
> 版本：0.1.0 | 创建：2026-05-20 | 下次审查：Phase 0.5 完成后

---

## 风险矩阵

用 影响 × 概率 来排优先级。每个风险标注：**影响**（高/中/低）和 **概率**（高/中/低）。

---

## 一、技术风险

### R1：视频角色一致性崩坏

| 属性 | 值 |
|------|-----|
| 影响 | **高** — 如果角色在不同镜头中看起来像不同的人，整个视觉体系不可用 |
| 概率 | **高** — 当前图→视频模型对角色面部保持能力普遍不足 |
| 触发条件 | Phase 0.5 视频生成测试 |
| 预警信号 | 3 次生成中 2 次角色面部明显变形 |
| 缓解方案 | 降级为 Slideshow + 运镜模式；缩短镜头时长（3-4 秒每镜减少变形概率）；使用更简单的角色视觉锚点 |
| 止损线 | 如果在 20 次视频生成后仍无法获得 3 个以上可用的连续镜头，放弃全动态视频方案 |
| 状态 | ⚠️ 待验证 |

### R2：Suno 中文歌词音乐质量不稳定

| 属性 | 值 |
|------|-----|
| 影响 | **高** — 音乐是核心产出物，不好听一切白费 |
| 概率 | **中** — Suno 中文能力在持续改进，但非主流语言仍是弱项 |
| 触发条件 | Phase 0.5 音乐生成测试 |
| 预警信号 | 10 次生成中可用率 < 30% |
| 缓解方案 | 降低歌词复杂度（减少文言/生僻词）；切换为纯器乐+人声采样模式；使用英文 Suno + 中文配音 overlay |
| 止损线 | 30 次生成后仍无法获得满意结果，考虑降低音乐复杂度或换模型 |
| 状态 | ⚠️ 待验证 |

### R3：AI 平台 API 服务中断或大幅涨价

| 属性 | 值 |
|------|-----|
| 影响 | **中** — 短期会阻断生产，但有多模型备选 |
| 概率 | **低** — 行业竞争激烈，涨价空间有限 |
| 触发条件 | evolink 或底层模型 API 不可用/提价 > 50% |
| 缓解方案 | 模块 07 中已列出每个环节的 2-3 个备选方案；AudioCraft MusicGen 可本地运行作为兜底 |
| 止损线 | 单 MV 成本超过 $20 时启动成本审查 |
| 状态 | ✅ 已缓解 |

### R4：Agent 技术栈选择错误

| 属性 | 值 |
|------|-----|
| 影响 | **中** — 选错框架会导致返工，但不影响文本阶段 |
| 概率 | **中** — Agent 框架领域变化快 |
| 触发条件 | Phase 1 结束前做技术选型 ADR |
| 缓解方案 | 先用手动+模板跑通 3 期，再决定是否需要 Agent 框架；优先评估 Mastra（storyboard 项目使用）、LangChain、手写 |
| 止损线 | 单 Agent 开发超过 2 周仍未产出可用结果，回到手动模式 |
| 状态 | ℹ️ 计划中 |

## 二、内容风险

### R5：第一期内容数据表现差（内容失败）

| 属性 | 值 |
|------|-----|
| 影响 | **高** — 所有框架设计的前提是"有人看" |
| 概率 | **中** — 第一期是试错，数据不理想是正常的 |
| 触发条件 | 前 3 期完播率持续 < 20%、互动率 < 1% |
| 预警信号 | 第一期数据低于同类 AI 内容中位数 |
| 缓解方案 | 使用迭代日志做根因分析（是角色不吸引人？歌不好听？标题不行？平台没推荐？）；第二期优先修复找到的根因；设置 3 期的试错窗口而不是 1 期就放弃 |
| 止损线 | 3 期后所有核心指标仍低于警戒线，暂停内容生产，重新评估角色选择和内容方向 |
| 状态 | ⚠️ 待首次发布 |

### R6：版权/审核问题导致内容下架

| 属性 | 值 |
|------|-----|
| 影响 | **中** — 单期内容下架，可修改重发 |
| 概率 | **低** — 孙悟空是公共领域角色，框架已有版权安全设计 |
| 触发条件 | 平台审核不通过 / 版权方投诉 |
| 预警信号 | 视觉设定与某现代作品"雷同感"被人指出 |
| 缓解方案 | 保留所有设计过程的文字记录（证明是独立创作）；准备 2 套视觉方案（备份）；下架后 24 小时内修改争议点重发 |
| 止损线 | 同一角色被驳回 2 次则放弃该角色的视觉化 |
| 状态 | ✅ 已缓解 |

### R7：角色选择失误（选了不合适/不吸引人的角色）

| 属性 | 值 |
|------|-----|
| 影响 | **中** — 浪费一个角色包的制作时间 |
| 概率 | **低** — 首个角色孙悟空是经过验证的高认知度角色 |
| 触发条件 | Phase 3 第二角色选择 |
| 缓解方案 | 第二个角色选择前先做"角色热度预判"（在小范围投票测试认知度和兴趣度）；选择与孙悟空有明确关系/对比的角色（哪吒/二郎神）降低风险 |
| 止损线 | 一个角色从填写到发布超过 2 周且数据不理想，不做第三期 |
| 状态 | ℹ️ 远期关注 |

## 三、运营风险

### R8：单人产能瓶颈

| 属性 | 值 |
|------|-----|
| 影响 | **中** — 更新频率不稳定会导致观众流失 |
| 概率 | **高** — 单人从角色包到发布全流程，预计 3-5 天/期 |
| 触发条件 | 连续 2 次未能在承诺时间发布 |
| 预警信号 | 每期制作时间超过预期 50% |
| 缓解方案 | 定义"最小可行发布"——砍掉不必要步骤；建立模板让重复环节加速；Phase 5 Agent 化减少人工环节 |
| 止损线 | 如果单人产能长期无法满足每周 1 期的频率，降低为双周更 |
| 状态 | ⚠️ 需监控 |

### R9：平台对 AI 内容政策收紧

| 属性 | 值 |
|------|-----|
| 影响 | **中** — 可能导致限流或要求标注 AI 标签 |
| 概率 | **中** — 各平台 AI 政策在快速演变 |
| 触发条件 | 平台发布新的 AI 内容管理规则 |
| 缓解方案 | 主动在内容中标注 AI 生成部分；增加人类创作参与度（人工写歌词、人工剪辑、人工审核）；考虑混合实拍素材 |
| 止损线 | 如果主要平台禁止 AI 生成音乐/视频内容，考虑转为人+AI 协作模式（人类演唱/拍摄+AI 辅助） |
| 状态 | ⚠️ 需关注政策动态 |

### R10：创作倦怠

| 属性 | 值 |
|------|-----|
| 影响 | **高** — 创作者放弃则项目终止 |
| 概率 | **中** — 高强度的单人创作容易倦怠 |
| 触发条件 | 连续 1 个月无新内容产出 |
| 预警信号 | 创作过程中的"烦躁感"增加、"为做而做"的心态 |
| 缓解方案 | 设定每周创作时间上限（不超过 15 小时）；在不好玩的时候暂停而不内耗；积累 2-3 期的素材储备作为缓冲 |
| 止损线 | 倦怠感持续 2 周以上，降低频率或只做最喜欢的那部分 |
| 状态 | ℹ️ 自我警觉 |

## 四、战略风险

### R11：框架设计过度，执行不足

| 属性 | 值 |
|------|-----|
| 影响 | **高** — "纸上完美的框架"从未被实际验证 |
| 概率 | **中** — 文档已经 10 个模块但实际产出只有 1 个角色包 |
| 触发条件 | Phase 1 结束后仍未产出任何实际媒体内容 |
| 预警信号 | 连续新增模块文档而不推进 Phase 0.5 工具验证 |
| 缓解方案 | **立即停止新增模块文档，优先执行 Phase 0.5 工具链验证**；每新增一个文档必须同时推进一个实际产出 |
| 止损线 | 本文档完成后，下一个动作必须是 Phase 0.5 的第一步 |
| 状态 | ⚠️ 当前风险 |

### R12：商业变现路径不清晰

| 属性 | 值 |
|------|-----|
| 影响 | **低**（现阶段） — 框架定位是"先服务个人创作" |
| 概率 | **低** — 模块 06 已有商业方向规划 |
| 触发条件 | 项目进行了 6 个月但无收入 |
| 缓解方案 | 前 6 个月专注内容和品牌积累；6 个月后评估模块 06 的四个商业方向 |
| 止损线 | 目前不需要止损 |
| 状态 | ℹ️ 远期关注 |
